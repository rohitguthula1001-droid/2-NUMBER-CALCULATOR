# 🧮 2 Number Calculator

A simple beginner-friendly calculator program that performs basic mathematical operations on two numbers.

This project was created as a practice project while learning programming fundamentals such as **input/output, variables, conditional statements, loops, and basic arithmetic operations**.

## ✨ Features

The calculator can perform the following operations:

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Power
- ❌ Exit the calculator

It also handles **division by zero** to prevent invalid calculations.

## 🛠️ Concepts Used

This project demonstrates some basic programming concepts:

- Variables
- User input and output
- if-else / conditional statements
- while loops
- Arithmetic operators
- Basic error handling
- Functions

## 🚀 How It Works

1. The program asks the user whether they want to use the calculator.
2. The user enters two numbers.
3. The program displays a menu of available operations.
4. The user selects an operation.
5. The calculator performs the selected calculation.
6. The user can continue using the calculator or exit.

## 📚 Learning Purpose

This project was built as a beginner programming project to understand how different programming concepts can be combined to create a functional application.

It is a small project, but it helped me practice the fundamentals needed for larger programming projects.
